# 斗破苍穹角色立绘

供斗破 1.4 角色卡按人物姓名远程加载。共 42 名角色、66 张立绘，每名角色最多 3 张。

- `portraits/manifest.json`：人物、常用别名与立绘路径。
- `portraits/catalog.json`：选图来源文件名和去字标记。
- `reader.html`、`status.html`：正文与状态栏前端；PNG 角色卡已经内置对应内容。
- `portrait-runtime.js`：共享图片选择逻辑。构建时将 `__PORTRAIT_MANIFEST__` 替换为清单 JSON。
- `variable-editor.js`、`variable-schema.js`：当前消息变量的增删改与结构处理。
- `status-view.js`：状态栏方框、人物与物品的显示和变量路径。
- `regex-config.json`：配套正则配置元数据。

图片优先从 GitHub Raw 加载，失败后尝试 jsDelivr；清单读取失败时使用卡内清单。状态栏中的左右按钮切换同名角色的图片，正文头像随之同步。正文气泡内不显示立绘。彩鳞、美杜莎女王、萧熏儿、药尘等别名映射到对应人物。

在状态栏设置中开启“编辑变量”，然后双击需要修改的方框。文字、数字、分组和列表都使用普通输入项；可新增、重命名或删除，最后点击左下角“保存”统一写入所在消息，变量管理器同步更新。未保存时仅修改草稿，若同一字段已被其他操作改变则提示冲突并保留草稿。支持“取消本项”和“放弃修改”。

状态栏不再显示“炼药师品级”和“灵魂境界”，变量中的原始数据保留。

普通正文使用阅读界面；正文内含完整 HTML、代码块或独立前端时透传内容，让酒馆助手继续识别和渲染。其他正则与原角色卡设定保持不变。

1.4 保留状态栏启动修复：内嵌脚本使用 UTF-8 Base64 包装，避免酒馆代码块实体处理破坏脚本内容；可读源码保留在 `status-runtime.js`。无头浏览器覆盖双击编辑、统一保存、变量同步、立绘切换、正文头像和手机布局。

素材来自用户提供的本地图片，保留人物和背景；选中的扉页已清除标题等文字。项目不包含原始角色卡、世界书、模型权重或本地运行环境。
