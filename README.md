# 斗破苍穹角色立绘

供斗破苍穹 V1.3 修订角色卡按人物姓名远程加载。共 42 名角色、66 张立绘，每名角色最多 3 张。

- `portraits/manifest.json`：人物、常用别名与立绘路径。
- `portraits/catalog.json`：选图来源文件名和去字标记。
- `reader.html`、`status.html`：正文与状态栏前端；PNG 角色卡已经内置对应内容。
- `portrait-runtime.js`：共享图片选择逻辑。构建时将 `__PORTRAIT_MANIFEST__` 替换为清单 JSON。
- `variable-editor.js`、`variable-schema.js`：当前消息变量的增删改与结构处理。
- `regex-config.json`：配套正则配置元数据。

图片优先从 GitHub Raw 加载，失败后尝试 jsDelivr；清单读取失败时使用卡内清单。状态栏中的左右按钮切换同名角色的图片，同源正文气泡会同步。彩鳞、美杜莎女王、萧熏儿、药尘等别名映射到对应人物。

状态栏设置中的“编辑变量”支持文字、数字、布尔值、对象、数组、空值以及变量新增、重命名和删除。保存到所在消息的 MVU 数据，变量管理器随后自动刷新。保存前发现该项已被其他操作改动时会提示重新读取。

普通正文使用阅读界面；正文内含完整 HTML、代码块或独立前端时透传内容，让酒馆助手继续识别和渲染。其他正则与原角色卡设定保持不变。

素材来自用户提供的本地图片，保留人物和背景；选中的扉页已清除标题等文字。项目不包含原始角色卡、世界书、模型权重或本地运行环境。
